# 详细报告口径 · report-observation-v1

本次扩展把自动行情分析呈现为可核对的中文报告。报告是观察与条件预案，不增加下单、仓位或回测功能。

| 分类 | 本版规则 | 来源 / 边界 |
| --- | --- | --- |
| 已可编码 | 四周期已收盘行情、MACD(10,20,5)、KDJ(9,3,3)、RSI(6,12,24)、成交量 | 复用项目已有计算与确认规则 |
| 已可编码 | 已锁定且有效的 B2/B3 或 S2/S3、上级冲突、现价净盈亏比 | 复用 `rt-right-side-v1`，解释层不能升级结论 |
| 工程补齐 E | EMA5/10/20/40/60/80，`ewm(span=n, adjust=False, min_periods=n)` | 用于复现参考报告的观察维度；不等同于课程双倍 SMA，不生成新买卖点 |
| 工程补齐 E | 默认以 4H 展开报告，对照 1D/1W 背景及 1H 结构 | 固定展示选择，不代表自动选择最佳周期 |
| 工程补齐 E | 从 4H 已有关键位中选择收盘价上下最近观察边界；输出上破回试、下破回抽、区间等待三种条件情景 | `report-observation-v1`；边界不是自动止损，也不把均线触及称为二买/三卖 |
| 工程补齐 E | 历史报告保存当时的紧凑指标、关键位、信号摘要及条件预案 | 保留分析截止时间；不保存原始 K 线数组，不用后续数据重写旧报告 |
| 暂缓 | 订单流 Delta/CVD、持仓量、资金费率、交易所/链上资金净流入 | 尚未接入数据源，报告只声明缺失，不推断资金行为 |
| 暂缓 | 识别截图、自动交易、胜率与收益预测、按账户定仓 | 不在本版范围 |

课程分析工作流提供“背景 → 结构 → 确认 → 风险 → 替代路径”的组织方式。本版保留原项目的缠论实现，未把它改称课程均线段体系。三种条件情景是未来观察路径，不等同于课程三种获利模式，也不声称当前已确认。

报告事实均以已收盘 K 线计算；现价单独标注。必需周期缺失或过期时不提供可用情景。单周期有缺口时，不使用它生成情景。无模型或模型校验失败时仍可查看本地数据，但结论保持“无有效技术结论”。模型自由文本与本地指标解释分开显示，最终状态始终服从本地复核。

关键参数及成本沿用 Settings：手续费与滑点均为单边费率，净盈亏比按双边成本核算。报告未取得账户风险预算，不能输出仓位大小或杠杆建议。EMA 边界会随之后收盘更新，本报告保存的是当时价格，不作长期固定价位。

## 图表展示口径 · chart-observation-v1

图表作为独立行情观察窗口放在报告上方，不改动报告生成与复核链路。

| 分类 | 图表规则 | 来源 / 边界 |
| --- | --- | --- |
| 已可编码 | K 线、EMA、MACD、KDJ、RSI、笔、线段、中枢与买卖点 | 复用当前后端计算；图表不另算一套指标或结构 |
| 工程补齐 E | 默认 ETH / 4H，产品与周期可切换，图层可单独开关 | 参考「缠论」项目的交互，用本地 KLineChart 9.8.9 绘制 |
| 工程补齐 E | 已收盘且 `ts + duration <= analysis_as_of` 的数据才进入图表结构；未收盘报价单列 | 防止将正在形成的 K 线当作已完成结构 |
| 工程补齐 E | 标签按极值锚点落图，状态按 `known_at`、`locked_at`、`active`、`invalidated` 判定 | 锚点时间不是当时可交易时间；结构确认也不等于多周期和风控已通过 |
| 工程补齐 E | 当前图表与历史报告各自标明时间；同产品/周期增量刷新保留拖动缩放位置 | 不是历史报告快照回放，不用新行情覆盖已保存的报告 |
| 工程补齐 E | 60 秒内复用行情；网络失败显示质量问题与旧数据时间 | 不把缓存刷新时间说成最新收盘时间，不用模型补造缺失行情 |
| 暂缓 | 任意日期历史回放、用户绘图持久化、订单交互 | 本次只增加观察图 |
